# 扣篮协议 · 26 周

一个单页训练执行看板：把「170cm / 68kg，26 周内完成 T1 扣篮」拆成可勾选、可测、可改方案的 26 周。

纯静态站点（HTML + CSS + 原生 JS），无构建步骤、无外部依赖、无后端。

## 内容

- **完成标准 T1–T4**：从 2.90m 筐 + 5 号球，到标准筐 + 7 号球，各自的摸高门槛与概率
- **八厘米杠杆**：助跑技术、单脚改型、体脂、踝刚、发力率、力量补丁、球筐处理、不减损
- **26 周分块**：逐周的力量百分比、弹性强度、技术模块，可勾选，进度存本地
- **每周模板**：4 练 + 3 次球 + 休息日，90 分钟封顶，附三条硬规则
- **测试与 Go/No-Go**：W0/W5/W9/W13/W17/W21/W26 七次实测，带达标判定
- **技术模块**：助跑节奏、摆臂、目标触击、球处理四块，附抓不住球的四种处理
- **红线与挑战日流程**

## 使用

打开页面即可。勾选周次、填写摸高实测值会自动算差值与是否达标。

- 记录保存在浏览器 `localStorage`，**不上传、不同步**；换设备或清理浏览器数据会丢。
- 顶部「开始日期」决定"当前第几周"的高亮与进度环。
- 「重置记录」清空所有勾选与测试值。

## 说明

训练内容基于《精英垂直弹跳学院》（Chris Barnard / Elite Vertical Academy，改良三相训练，16 周 4 阶段）改造而来，评估结论：模板质量 7.8/10，但作为扣篮执行方案只有 6.5——缺助跑技术、球筐处理与个体化负荷管理，本页补齐这些缺口。
